- (decision) Completed = task has an official_reports row (11.4 completion fact); history lists only those. Authorization by session: Responsable own team (getOwnTeamTaskId), Employe current assignment (getAssignedEmployeeTask); same record for both roles, no section filtered by role.

- (decision) Download is an authorized endpoint streaming the official file (no short-lived URL); PDF via files readStoredFile (fail closed 409 REPORT_FILE_NOT_READY), sha256 of bytes checked against stored value; Word from storage ref. Official candidate file only, never another candidate.
- (decision) Lineage: replacementOf/replacedBy entries carry task/audit IDs only when the viewer is authorized for that task, else accessible=false with no IDs; replaced original keeps its own record unchanged; replacement links to a not-yet-completed task still shown as relation.
- (decision) UI scope: web H1 panel for Responsable (web is Responsable-only); Employe is served by API + typed client; mobile screen and on-device file saving are out of scope (no file-system/share dependency in apps/mobile; deferred-work entry). Not a business rule.
