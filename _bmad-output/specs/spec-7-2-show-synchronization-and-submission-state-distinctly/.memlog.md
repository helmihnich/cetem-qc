- (decision) Triggers in 7.2: explicit retry action and right after a successful submission request. Automatic triggers (app start, reconnect, foreground, after save) stay with 7.3 per the 7.1 hand-off. A run starts only when online, transport non-null and offline-authorization state is online-authorized for that employee (no sync before server revalidation, EXPERIENCE OD-01).
- (decision) Lifecycle rule: the task's latest submit item (highest sequence) decides: unresolved → pending; accepted → Submitted; rejected → acceptance blocked; conflict → conflict; no submit item → Brouillon. Follows EXPERIENCE state table and UX-DR4/DR5; no CETEM business rule involved.
- (decision) Read-only rule: locked whenever lifecycle is not Brouillon. Rejected and conflict stay locked; correction draft (8.2) and conflict resolution (8.1) unlock later. Follows EXPERIENCE (« never automatically return to editable Draft »).
- (decision) Transfer state for the relevant item (the unresolved submit item when pending, otherwise the task's unresolved sync-draft items): in-flight → en cours; retry-paused → échec du transfert + retry; blocked → synchronisation bloquée + retry; queued → en attente de synchronisation; none unresolved → last sync-draft outcome (accepted → Brouillon synchronisé — non soumis; rejected/conflict labelled) or « Non synchronisé » when no item exists.
